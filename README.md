# salary-prediction
Predict Salary Based on Experience

A simple Machine Learning project using Linear Regression to predict employee salary based on years of experience.

Project Overview

This project trains a Linear Regression model that learns the relationship between:

Input (X): Years of Experience
Output (y): Salary

The model predicts salary for new experience values.

Example:

2 years → ₹30,000
5 years → ₹60,000
6 years → predicted salary
